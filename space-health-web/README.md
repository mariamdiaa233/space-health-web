# Space Health Web Prototype

واجهة ويب عربية RTL لمشروع الساعة الذكية لمتابعة المؤشرات الصحية.

## تشغيلها على GitHub Pages
1. فك ضغط `space-health-web.zip`.
2. افتحي المستودع `space-health` على GitHub.
3. ارفعي **محتويات** المجلد مباشرة إلى جذر المستودع، بحيث تظهر `index.html` و`style.css` و`script.js` بجوار بعضها، وليس داخل مجلد فرعي.
4. من Settings → Pages اختاري مصدر النشر الصحيح (حسب إعدادك الحالي) وانتظري اكتمال النشر.
5. افتحي رابط GitHub Pages.

## ملاحظة مهمة عن الاتصال بالساعة
- الواجهة تحتوي محاكاة قراءات تجريبية لتوضيح شكل النظام.
- زر Bluetooth يستخدم Web Bluetooth، لكنه لا يتصل بأي ساعة عشوائية تلقائيًا.
- يجب أن يطبق Firmware الساعة خدمة GATT وخصائص BLE المتوافقة.
- في `script.js` استبدلي `BLE_SERVICE_UUID` و`BLE_CHARACTERISTIC_UUID` بالقيم الفعلية التي ستعتمدونها في برمجة الساعة.
- صيغة الرسالة المتوقعة حاليًا JSON مثل:
  `{"glucose":108,"heart":72,"spo2":98,"temp":36.7}`
- عدّلي `handleBleData()` إذا كان المتحكم يرسل صيغة مختلفة.
- Web Bluetooth يحتاج متصفحًا متوافقًا واتصال HTTPS، وقد لا يعمل مباشرة من متصفح iPhone.

## تنبيه طبي
هذه نسخة أولية تعليمية وليست جهازًا طبيًا معتمدًا. بيانات المحاكاة ليست قراءات حقيقية، ولا يجوز استخدامها لاتخاذ قرارات علاجية. قياس الجلوكوز من المعصم يحتاج مستشعرًا وتقنية مثبتة واختبارات تحقق سريرية.
